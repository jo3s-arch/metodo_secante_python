# Metodo de la Secante - Aplicación de escritorio

Aplicación de escritorio en Python para el Método de la Secante (Análisis Numérico).

Instrucciones básicas de ejecución (local):

1. Crear y activar entorno virtual:
   python -m venv env
   # Windows
   env\Scripts\activate
   # macOS / Linux
   source env/bin/activate

2. Instalar dependencias:
   pip install -r requirements.txt

3. Ejecutar la aplicación:
   python main.py

Todos los textos de la interfaz están en español.
